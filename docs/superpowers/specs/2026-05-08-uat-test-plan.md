# Prody UAT — Пълен процес от край до край

## 1. Продукт — Създаване и Зареждане

- [ ] **1.1** Влез като админ → Каталог → Нов продукт
- [ ] **1.2** Попълни име, цена (5.00 лв), доставна цена (3.00 лв), категория
- [ ] **1.3** Въведи количество 50 бр.
- [ ] **1.4** Запази → трябва да се отвори RestockForm модал
- [ ] **1.5** Разпредели: 20 бр. Ботев, 20 бр. Бургас, останалите 10 → склад
- [ ] **1.6** Провери в детайли на продукта дали наличностите се виждат по обекти
- [ ] **1.7** Влез в складовите движения — трябва да има restock записи
- [ ] **1.8** Отиди в Настройки → Мин. количества → задай мин. к-во = 5
- [ ] **1.9** Редактирай продукта → полето "Наличност" трябва да е заключено
- [ ] **1.10** Промени цената → запази → трябва да работи без грешка
- [ ] **1.11** __Проверка:__ Няма поле SKU, няма поле Баркод

## 2. Трансфер между обекти

- [ ] **2.1** От детайли на продукта → Складова наличност → Трансфер
- [ ] **2.2** От склад → Ботев, 5 бр.
- [ ] **2.3** Провери наличностите обновени
- [ ] **2.4** Опитай трансфер с количество > налично → трябва да даде грешка
- [ ] **2.5** Провери движенията — трябва да има transfer_out + transfer_in

## 3. Продажба (POS)

- [ ] **3.1** Влез като админ → Запиши продажба → избери "Ботев"
- [ ] **3.2** Добави 2 продукта в количката (различни количества)
- [ ] **3.3** Избери "Кеш" като метод на плащане
- [ ] **3.4** Кликни "Завърши продажба"
- [ ] **3.5** __Проверка:__ Не трябва да иска пак плащане
- [ ] **3.6** Повтори с "Карта"
- [ ] **3.7** Отиди в Продажби → провери дали продажбите се виждат с правилния метод
- [ ] **3.8** Провери наличностите на продуктите намалени в Ботев

## 4. Продавач — Заявки

- [ ] **4.1** Switch role → "Виж като продавач" → Ботев
- [ ] **4.2** Отиди в Заявки (продавач)
- [ ] **4.3** Провери дали ниските наличности се показват (ако има)
- [ ] **4.4** Търси продукт → добави в кошницата
- [ ] **4.5** Напиши коментар "Трябват за уикенда"
- [ ] **4.6** Изпрати заявка
- [ ] **4.7** __Проверка:__ Коментарът трябва да се вижда в кошницата преди изпращане
- [ ] **4.8** Провери историята — заявката трябва да е със статус "Чакаща"
- [ ] **4.9** Копирай URL от продаваческата заявка за справка

## 5. Админ — Обработка на заявки

- [ ] **5.1** Върни се като админ → Заявки (админ)
- [ ] **5.2** Намери заявката от продавача — трябва да е в "Чакащи"
- [ ] **5.3** __Проверка:__ Картата показва магазин, статус, коментар, брой продукти
- [ ] **5.4** Разгъни заявката → провери продуктите
- [ ] **5.5** Кликни "Прехвърли всички"
- [ ] **5.6** В диалога избери откъде да дойдат бройките
- [ ] **5.7** Изпълни → заявката трябва да се премести в "Обработени" със статус "Изпратена"
- [ ] **5.8** __Проверка:__ Коментарът от продавача се вижда

## 6. Продавач — Потвърждение

- [ ] **6.1** Върни се като продавач → Заявки → История
- [ ] **6.2** Заявката трябва да е със статус "Изпратена" и бутон "Потвърди"
- [ ] **6.3** Кликни "Потвърди" → диалог с количество
- [ ] **6.4** Намали количеството (симулирай частична доставка)
- [ ] **6.5** Добави коментар "Липсват 2 броя"
- [ ] **6.6** Потвърди
- [ ] **6.7** __Проверка:__ Статус става "Частична" с оранжев индикатор и получено/заявено
- [ ] **6.8** Кликни на реда → трябва да се покаже timeline

## 7. Админ — Проверка след потвърждение

- [ ] **7.1** Върни се като админ → Заявки
- [ ] **7.2** Заявката трябва да е в "Обработени" със статус "Частична"
- [ ] **7.3** __Проверка:__ Оранжев индикатор с получено/заявено
- [ ] **7.4** Кликни на продукта → timeline с всички статуси

## 8. Табло

- [ ] **8.1** Отиди на Табло
- [ ] **8.2** __Проверка:__ KPI карти (продукти, днес, месец, ниски наличности)
- [ ] **8.3** __Проверка:__ Пер-store revenue карти (Ботев, Бургас, Заимов)
- [ ] **8.4** __Проверка:__ Графики — продажби по дни, топ 5 продукти
- [ ] **8.5** __Проверка:__ Няма излишно бяло пространство в графиките

## 9. Отчети и Експорт

- [ ] **9.1** Отиди на Отчети
- [ ] **9.2** Задай период (от-до) → Покажи
- [ ] **9.3** __Проверка:__ KPI-тата се обновяват
- [ ] **9.4** Скрол до Експорт секцията
- [ ] **9.5** Избери период + магазин (или всички)
- [ ] **9.6** Кликни "По обекти" → трябва да се изтегли .xlsx файл
- [ ] **9.7** Отвори файла в Excel → провери дали има автофилтър, кирилица, форматиране
- [ ] **9.8** Повтори за "По продукти"
- [ ] **9.9** Повтори за "Пълен детайл"
- [ ] **9.10** __Проверка:__ Трите файла са различни и съдържат различни данни

## 10. Настройки

- [ ] **10.1** Отиди на Настройки
- [ ] **10.2** Категории → създай нова → редактирай → изтрий
- [ ] **10.3** Магазини → редактирай съществуващ → провери is_warehouse флага
- [ ] **10.4** Мин. количества → промени стойност → запази → ✓ иконка
- [ ] **10.5** Мин. количества → отвори продукта в детайли → провери дали мин. к-во се е променило
- [ ] **10.6** AI → провери дали настройките се зареждат

### 10.7 Имейл

- [ ] **10.7.2** Попълни SMTP настройки (Gmail App Password)
- [ ] **10.7.3** Добави получател
- [ ] **10.7.4** Избери ден и час за отчет
- [ ] **10.7.5** Маркирай/демаркирай секции за отчета
- [ ] **10.7.6** Запази
- [ ] **10.7.7** Кликни "Изпрати тестов отчет"
- [ ] **10.7.8** __Проверка:__ Мейлът пристига с HTML тяло и прикачен Excel файл

### 10.8 Потребители

- [ ] **10.8.1** Отиди на Потребители таб
- [ ] **10.8.2** __Проверка:__ Съществуващите потребители се виждат в таблицата
- [ ] **10.8.3** __Проверка:__ Роля, магазин, статус се показват правилно
- [ ] **10.8.4** Кликни "Добави" → попълни име, имейл
- [ ] **10.8.5** Избери роля "Продавач" → избери магазин
- [ ] **10.8.6** Генерирай парола → махни отметката за мейл
- [ ] **10.8.7** Създай → __Проверка:__ Паролата се показва в жълто поле
- [ ] **10.8.8** Копирай паролата → затвори диалога
- [ ] **10.8.9** Провери дали новият потребител се вижда в таблицата със статус "Поканен"
- [ ] **10.8.10** Редактирай съществуващ потребител → смени ролята → запази
- [ ] **10.8.11** Деактивирай потребител → статусът трябва да стане "Деактивиран"
- [ ] **10.8.12** __Проверка:__ Деактивиран потребител не може да влезе

## 11. Мобилна версия

- [ ] **11.1** Отвори на телефон/емулатор
- [ ] **11.2** Провери sidebar-а — отваря се, затваря се при избор на страница
- [ ] **11.3** Провери POS-а — количката е долу, продуктите горе
- [ ] **11.4** Провери заявките — картите се подреждат правилно
- [ ] **11.5** Провери таблото — KPI-тата се редят едно под друго

## 12. Edge Cases

- [ ] **12.1** Продажба без избран метод на плащане → трябва да покаже попап
- [ ] **12.2** Празна количка → бутон "Завърши" трябва да е деактивиран
- [ ] **12.3** Продукт с 0 наличност в магазин → не трябва да се показва в POS за този магазин
- [ ] **12.4** Заявка без коментар → трябва да може да се подаде (не е задължително)
- [ ] **12.5** Редакция на продукт → количеството е заключено
- [ ] **12.6** Трансфер от магазин без наличност → трябва да даде грешка
- [ ] **12.7** Изтриване на продукт с продажби → трябва да даде грешка или да мине
